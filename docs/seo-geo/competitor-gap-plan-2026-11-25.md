Our site already has meaningful initial HTML, canonical metadata, connected clinic/site/page schema, an indexable homepage, sitemap and verified Google Search Console ownership. This pass addresses two remaining technical opportunities rather than repeating that work:

- `MedicalClinic.hasMap` and `sameAs` now identify the **specific existing clinic Maps profile**. The profile's public presence does not establish clinic management access, operational verification or care quality. Phone/hours differences remain unresolved; no rating, review, coordinate, credential, outcome or procedure-location claim was added.
- An IndexNow ownership file and a submission script notify participating engines about published updates. The script submits only the canonical published route inventory, checks the deployed ownership file and each live page's status/canonical/noindex before posting, and distinguishes HTTP 200 from HTTP 202 pending key validation. CI runs it after deployment and production verification when published files changed. Notification failure is visible but does not invalidate an otherwise successful deployment. This is discovery plumbing, not a ChatGPT ranking integration or guarantee.

`npm run indexnow:check` makes no network requests. `npm run indexnow:submit` checks the live site and sends the notification. The ownership file is intentionally public protocol verification material. Do not submit unchanged URLs repeatedly or add draft/redirected URLs to the published inventory. IndexNow's participating-engine notification is independent of Bing Webmaster/Places account access.

## Content brief for separate approval

The useful opportunity is clearer, verifiable information for patients. Proposed scope: a substantive IVF pathway page and a physician evidence page, with links from appropriate existing sections only after approval. Keep the current homepage design.

1. Identify the clinic, neighbourhood, appointments and actual consultation confirmation process. State where every stage of care is performed and who is responsible, using approved facts.
2. Explain assessment, treatment alternatives, expected visit stages, practical travel considerations, follow-up and how patients receive an individual recommendation. A clinician must write/review consequential medical guidance and its sources.
3. Explain how to request an itemised estimate: consultation, tests, medicines, procedures, anaesthesia, laboratory, freezing/storage, later transfers and cancellation terms. Publish prices only when current, authorized and scoped; no invented package or outcome promise.
4. Publish verified clinician name, recognised qualifications, current council details and care roles with followable evidence. Record an actual reviewer and actual review date only after sign-off.
5. For any future aggregate outcome, define cohort, age group, treatment, denominator, time period and endpoint, with clinical review. If those data do not exist, omit the claim.

Do not copy promotional competitor text, publish a self-awarded “best” claim, or manufacture independent endorsements. Genuine professional affiliations, public educational work and accurate established directory records are potential external evidence when they exist; none were invented or solicited here.
